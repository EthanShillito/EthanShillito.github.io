Parent pandamonium

This was a game development coursework focused on tutorials and explaining mechanics. In this game the player must complete tasks around the house while looking after the baby that will try to crawl into danger. The sections discussed here are based on my contributions to the project, not an overview of everything in it.

A* pathfinding

For the movement of the baby I implemented the A* algorithm with a pathfinding grid (shown with the blue debug lines). This allows the baby to move across the map to the spots it chooses.

Baby Logic

I was also responsible for the logic of the baby movement. The baby will choose random spots on the pathfinding gird to move to. Then at given (range randomised) intervals it will pick (and highlight) a dangerous object, like the oven and try to move towards it for a set amount of time. If the baby reaches the danger object it is game over. To prevent this the player can pick up the baby and carry them elsewhere - although they can't perform tasks while holding the baby and so must put the baby back down.

Level Scripting

I also set up the success and fail states for the game, including the timer for tasks to be completed by and the end of level screens.

Level Design

Each member was responsible for designing one level for the game. I put together the final level which had the most tasks, danger items and obstacles around the room to slow the player down.

Menu Programming

Additionally I set up the logic for menu functionality to start a game, go to a specific level and to allow the player to skip the tutorial.
