Park Bubble Battle

My entry to the 2025 Global Game Jam. This is a two player split screen PvP game where players run around in a park shooting bubbles at each other.

Pooled Actor

With the intention of improved memory managment I created a pooled actor class for the bubbles. So that all bubbles to be used in the game are already loaded into memory and just placed in the correct world position when used.

Damage System

I also implemented a damage system with UI display to handle the bubbles dealing damage to the players and cause a game over if one runs out of health.

Water Meter

The game also has a water meter which must be partially full to shoot a bubble. Refilling requires moving near the fountain and disables attacks while refilling to prevent exploiting it for infinite ammo.
