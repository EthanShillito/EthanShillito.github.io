Attachable actors

A prototype for a game jam that makes use of a custom C++ component and the physics component to attach multiple actors together - functioning like a simple version of the ultrahand from Tears of the Kingdom.

Grabbable Objects

Certain objects in the world are able to be picked up, moved and rotated using the physics handle components in Unreal.

Attachment Point

When the player is holding a grabbable object and places one of its attachment points (shown in blue) next to another attachment point, on another grabbable or the player, they can press a button to call the attach function on the component to connect the two actors together. If the player picks the grabbable back up it will call the disconnecting method on each of its attachment points.

Spinning Character

The main character uses physics based movement to roll around the map. By spinning while having attached objects on it, it can scale walls by using them like legs while spinning.

Physics Constraint

Unfortualty I found that when chaining the physics constraint component multiple times the engine doesn't manage to keep the connections rigid, even with the settings to do so. Making it hard to use this approach for more complex legs and gameplay that had been intended with this mechanic.
